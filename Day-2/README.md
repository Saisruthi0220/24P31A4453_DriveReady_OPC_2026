# Day 2 – Prompt Engineering, Memory & Python Fundamentals for AI Agents

## Overview

Day 2 focuses on the core concepts required to develop intelligent and reliable AI agents. This session explores prompt engineering, conversation management, memory handling, structured outputs, and essential Python programming concepts used in building AI-powered applications.

The practical examples are based on a customer-support assistant for **Sweet Crumbs Home Bakery**.

## Learning Objectives

- Understand LLM conversation structures and message roles.
- Design effective system prompts for AI assistants.
- Explore zero-shot and few-shot prompting techniques.
- Generate structured JSON responses from LLMs.
- Understand conversation history and memory management.
- Apply Python dictionaries, functions, and decorators.
- Handle runtime errors using exception handling.

## Topics Covered

### 1. LLM Messages and Roles
- System messages
- User messages
- Assistant messages
- Understanding conversational context.

### 2. System Prompt Engineering
- Defining the AI assistant's role.
- Providing business-specific information.
- Establishing instructions and response guidelines.
- Controlling response formats and behavior.

### 3. Zero-Shot and Few-Shot Prompting
- Understanding zero-shot prompting.
- Implementing few-shot prompting with examples.
- Classifying customer messages into orders, questions, and complaints.

### 4. Structured JSON Outputs
- Generating structured responses using JSON.
- Working with `json.dumps()` and `json.loads()`.
- Handling JSON parsing errors using `try/except`.

### 5. Conversation Memory Management
- Maintaining conversation history.
- Managing user and assistant messages.
- Understanding context windows and token limitations.
- Implementing limited conversation memory using `MAX_TURNS`.

### 6. Python Fundamentals for AI Agents
- Dictionaries and key-value pairs.
- Safe dictionary access using `.get()`.
- Functions with parameters and return values.
- Type hints and docstrings.
- Python decorators.
- Exception handling using `try` and `except`.

## Practical Implementation

The session includes hands-on exercises such as:

- Creating a business menu using Python dictionaries.
- Implementing a `get_price()` function.
- Classifying customer messages using few-shot examples.
- Generating structured order information in JSON.
- Maintaining limited conversation history.
- Using decorators to add functionality to Python functions.
- Handling API errors and exceptions gracefully.
